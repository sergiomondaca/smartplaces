# Smart Home Orchestrator

vamos a crea un sitio denominado Smart Places, es una empresa de servicios de automatización, IOT, desarrollo de soluciones integrales de seguridad, survillance, confort, alarmas, orquestados a través de la integración de una app que permite agregar distintos tipos de dispositivos de distintas marcas y distintos dispositivos. 
La empresa entrega paquetes de soluciones para clientes residenciales, de departamentos, empresas.
